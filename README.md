## Installation

1. Clone the repository: `git clone https://github.com/irenascent/OracleForge.git`
2. `cd OracleForge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure OracleForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
